### Project Description
A full-fledged traffic management system... for snails. Complete with signals, lane discipline, and speed monitoring — because if humans get traffic lights, so should our shelled friends.

### The Problem (that doesn't exist)
Snails have been crossing gardens, footpaths, and driveways completely unregulated for millions of years. No signals, no lanes, no rules — total chaos at a pace of 0.03 mph. Someone had to step in before things got... slow and out of hand.

### The Solution (that nobody asked for)
We built a miniature traffic control system exclusively for snails — complete with tiny red-yellow-green signals, a "speed" camera to catch reckless snails going rogue, and a control dashboard to monitor snail congestion in real time. Order has finally come to the snail kingdom.
